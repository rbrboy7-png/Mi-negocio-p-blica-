MI NEGOCIO PUBLICA

Este repositorio contiene el servidor para preparar la generación de imágenes mediante inteligencia artificial.

PUBLICACIÓN EN RENDER

1. Conectar este repositorio de GitHub con Render.
2. Elegir Web Service.
3. Comando de compilación: npm install
4. Comando de inicio: npm start
5. Añadir la variable privada OPENAI_API_KEY en la configuración de Render.

IMPORTANTE

No publicar la clave API en GitHub.
La generación real de imágenes requiere que la API tenga facturación y saldo disponibles.
La aplicación web deberá conectarse a la dirección pública del servidor para generar imágenes.
